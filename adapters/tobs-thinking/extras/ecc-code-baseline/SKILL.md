# 代码岗基线（摘自 ECC，不是整包）

出处：[affaan-m/ECC](https://github.com/affaan-m/ECC)，MIT。这里只保留四条能在 DSH 里用手做的流程。不复制其余 agents、hooks 或安装器。FCC 不是必选项。Claude Code 的 PreToolUse 之类钩子在这里没有对应的自动执行面，不要假装它们会跑。

## 先搜再改

改之前先在当前仓库里找已有函数、测试和文档。能接上就不要平行再写一套。

## 测试作证据

先写出会失败的检查，再改，再跑同一条检查。没跑过的检查不能写成已通过。

## 安全复核

看这次改动会不会扩大谁能读、谁能写、谁能批准。密钥不进仓库、不进聊天记录。不确定就停下来问。

## 换一份上下文复查

复查时不要只顺着刚才的思路再看一遍。列出改了什么、哪条测试覆盖它、还没测什么。
